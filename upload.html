Informativa Privacy AI

La presente informativa descrive come trattiamo i tuoi dati per la valutazione del merito creditizio:

  • Finalità: I dati sono raccolti per l'istruttoria della pratica di mutuo.
  • Analisi AI: I documenti sono analizzati tramite OpenAI API per estrarre dati reddituali. I dati non vengono usati per addestrare l'AI.
  • Sicurezza: I file sono criptati su server Google Cloud/Firebase.
  • Conservazione: I dati verranno conservati per un massimo di 180 giorni.

Cliccando sulla checkbox, presti il consenso esplicito a questo trattamento tecnologico.
