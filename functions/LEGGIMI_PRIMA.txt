TU DEVI FARE SOLO QUESTO:

1) Sostituisci la tua cartella "functions" con quella contenuta in questo ZIP
   oppure carica i file nel repository GitHub mantenendo le stesse cartelle.

2) UNA SOLA VOLTA crea il PIN segreto.
   Apri il Terminale nella cartella del progetto Firebase e scrivi:

   firebase functions:secrets:set DELETE_DOCUMENT_PIN

3) Premi INVIO.
   Firebase ti chiederà il valore.
   Inserisci il PIN/password che vuoi usare quando elimini documenti dalla dashboard.
   Mentre lo digiti potrebbe non comparire nulla: è normale.
   Premi INVIO alla fine.

4) Poi fai il normale commit/push su GitHub.
   Il tuo workflow Deploy Firebase Functions può distribuire normalmente tutte le Functions.

   Oppure manualmente:

   firebase deploy --only functions --project consulenza-credipass

5) Dopo il deploy:
   - apri la dashboard
   - premi ELIMINA
   - inserisci lo stesso PIN
   - la Cloud Function cancellerà il documento lato server

NON APRIRE LE STORAGE RULES AL DELETE PUBBLICO.
